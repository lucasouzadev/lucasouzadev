## Produtos em destaque

### Dialetto

Armazenamento, versionamento e compartilhamento de músicas em desenvolvimento. Um espaço para organizar projetos de áudio e acompanhar suas versões, com experiência web e mobile.

**Tecnologias:** React, TypeScript, Capacitor e Go. **Código atual privado.**

[Conhecer o Dialetto](https://dialetto.club) · [Base pública (fork)](https://github.com/lucasouzadev/vault-dialetto) · [Builds e testes](https://github.com/lucasouzadev/dialetto-builds)

### Monologue

Aplicativo de notas em formato de conversa: um lugar para registrar pensamentos, continuar ideias e reencontrar o que foi escrito. A proposta parte de uma experiência mobile com armazenamento local.

**Tecnologias:** React Native, Expo, TypeScript e SQLite. **Código privado.**

[Builds e testes](https://github.com/lucasouzadev/monologue-builds)

### Ajudaê

Marketplace de logística urbana que conecta clientes e prestadores para mudanças, fretes e entregas. O projeto reúne o aplicativo e ferramentas de operação em um monorepo.

**Tecnologias:** React Native, Expo, TypeScript e Supabase. **Código público.**

[Explorar o projeto](https://github.com/lucasouzadev/ajudae_app)

### ucorvo&ulobo

Aplicativo para clubes de leitura e escrita, com comunidade, conversas e recursos para aproximar leitores e autores. O projeto também inclui um CRM web.

**Tecnologias:** React Native, Expo, React, TypeScript e Supabase. **Código privado.**

### TeamForge

Workspace colaborativo para pequenos times, com organização visual de ideias, tarefas e arquivos de projeto. Inclui integrações com Google Calendar e Google Drive.

**Tecnologias:** Next.js, TypeScript, Tailwind CSS e Supabase. **Código privado.**
